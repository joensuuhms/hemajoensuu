# HEMAJoensuu

Website of **Joensuun historiallisen miekkailun seura ry** (JoHMS), a historical European martial arts (HEMA) club in Joensuu, Finland.

**https://hemajoensuu.fi**

The site presents the club and the sport, training times and places, news and courses, a photo gallery and answers to frequently asked questions. It is written in Finnish.

## Built with

- [Eleventy](https://www.11ty.dev/) – static site generator
- [Decap CMS](https://decapcms.org/) – browser-based content editing at `/admin/`
- GitHub Pages and GitHub Actions – hosting and automatic publishing
